feat: 不烧心 —— DSH 文风层 + 短剧改写引擎

把「不烧心」这个网络梗做进 DeepSeek Harness。

主体是文风层：把「快而便宜的路有坑」这类技术取舍，从一句正确的废话
换成一个会记住的说法。走 systemPrompt.section 在生成前注入 ——
宿主没有改写助手回复的钩子（assistant/message 是 append 之后的通知事件，
客户端在流式帧上就渲染完了），这是唯一有效路径。

三块功能：
- 文风层（默认开）：四档强度 关/轻/中/重，只改说话方式，不演短剧
- 短剧改写引擎：bushaoxin_rewrite / bushaoxin_drama，五个独立旋钮
  （preset / slots / density / flip / seed），辣度不是音量而是形状
- 门诊部：/bushaoxin 按会话工具调用量出烧心指数病历（娱乐）

两条底线写死在代码里：每篇末尾永远附一行真实技术结论，不可关闭；
绝不为配合段子编造技术事实。

零依赖，35 项断言全通过。引擎是纯函数，同输入同输出。
