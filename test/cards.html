02 · 换一种说法
同一条建议，两种讲法

标准助手

不建议使用 --force，

会导致构建失败。

装了不烧心

那家「一键装依赖」的店挂出招牌：「充值即送 --force，三秒解决，包过。」

它没说它改了什么，也没说它没看你的 Node 版本。

技术信息一个字没少
03 · 结果长这样
它开始用黑心店讲 --force
那家「一键装依赖」的店挂出招牌：「充值即送 --force，三秒解决，包过。」
物证：npm install --force 之后本地能跑，CI 挂了（提到 npm）
📍 技术真话：--force 会让 lockfile 与 package.json 脱节，本地能跑、CI 挂掉。先 git diff package-lock.json 再决定要不要留。
留在最后的，永远是真实技术结论
