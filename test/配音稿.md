> 用途：A 版（技术向 90 秒）/ B 版（业务向 90 秒）的解说词。
> 每一段都是**独立的一句**，段落之间就是停顿点 —— 方便你在配音工具里逐段生成、再拼轴。

## 配音参数建议

| 项 | 建议 |
|---|---|
| 音色（A 版） | **云希**（青年男声，清爽偏快）—— B站科技区最常用 |
| 音色（B 版） | **晓晓**（青年女声，温和自然） |

| 语速 | 正常偏快（约 1.05–1.15×）。这个题材不拖 |
| 情绪 | **不要播音腔**。用"同事跟你讲件事"的语气 |
| 音量 | 旁白 −6 dB，留空间给音乐和演示音效 |
| 采样 | 48 kHz / 单声道即可（人声不需要立体声） |

- **剪映**：文本 → 朗读 → 选音色 → 导出音频（你已装，`C:\Users\li123\AppData\Local\JianyingPro`）
- **Edge 浏览器**：打开一段文本 → 右键「大声朗读」→ 选晓晓/云希 → 录系统声音

## 录音与拼轴提示

1. **逐段生成，别一口气生成整篇**——一口气生成的语气会平，逐段可以在工具里单独调语速。
2. **第 5 段最长（22–24 秒）**，如果听感拖，把它拆成两句分别生成再拼。
3. **金句单独重录一遍**（第 4 段、第 9 段 / B 版第 4 段、第 8 段），剪辑时可以对同一句话做两版：一版正常音量、一版略慢略重，用作片尾回响。
4. **不要在句号处硬切**——留 150–250 ms 静音，人耳会觉得自然。
5. **导出格式**：WAV 48 kHz；如果要压，用 192 kbps 以上的 AAC。
